## What remains uncertain

- Full browser/Electron workflow execution for all 84 pages, en/vi, roles, layouts, components and navigation is pending implementation/test fixtures. Source trace coverage is complete enough to plan, but it is not a runtime parity certificate.
- No real Google/SMTP/PayOS/SePay/YouTube/Tactiq/LLM/R2/Cloudinary/Unsplash transaction was invoked. Provider ownership, registrations, quotas/terms and failure/retry behavior require configured genuine integration tests. The embedding model HTTP tests did not simulate these integrations.
- No local database/Redis deployment or migration was started, no production data inspected, and no restore/uninstall/upgrade tested. Existing endpoint declaration counts do not prove handlers can execute against an empty cluster.
- Supported OS/CPU matrix, native resource size/RAM/CPU limits, installer signing/update distribution and legal redistribution review are open implementation gates. Electron/PostgreSQL/CPU FastAPI is a source-supported candidate, not a demonstrated all-platform bundle.
